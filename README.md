# 折叠雨伞 · 结构 3D 可视化

一个基于 **Three.js** 的折叠雨伞（三折伞）组成结构 3D 交互演示：程序化建模雨伞全部零部件，
用连杆机构运动学实时驱动开合动画，可用于结构教学与机构原理展示。

![预览](#) （运行后见页面）

## 运行

纯静态页面，无需构建。任选一种方式启动本地服务器：

```bash
# 方式一：Python
cd umbrella-form
python3 -m http.server 8410
# 打开 http://localhost:8410

# 方式二：Node
npx serve umbrella-form
```

> 注意：需通过 HTTP 访问（ES Module 限制，直接双击 index.html 用 file:// 打开无法运行）。

## 功能

| 功能 | 说明 |
| --- | --- |
| 开合动画 | 页面加载后自动演示一次开伞；底部滑块可手动收合/展开任意位置；「开合演示」循环播放 |
| 机构联动 | 上巢（固定铰点）+ 长骨 + 骨关节 + 尾骨 + 撑骨 + 下巢（滑套）构成真实连杆系统，中棒三节同步伸缩 |
| 部件查询 | 右侧列表或直接点击 3D 零件，查看 12 类部件的中英文名称、数量、材质与作用；列表点击可聚焦 |
| 高亮定位 | 悬停/选中部件自发光高亮，3D 标签与列表双向联动 |
| 隔离显示 | 详情卡中「仅显示此件」，单独查看某个部件 |
| 透视伞面 | 伞面变半透明，露出完整骨架 |
| 爆炸视图 | 全部零件沿轴线/径向分离，自动拉远取景 |
| 其他 | 部件标签开关、自动旋转、重置视角；拖拽旋转 / 滚轮缩放 / 右键平移；Esc 取消选择 |

## 部件清单（12 类 · 47 件）

伞面（伞布）、长骨 ×8、尾骨 ×8、骨关节 ×8、撑骨 ×8、下巢、上巢、中棒（3 节）、弹簧、伞柄、伞顶珠、骨尾珠 ×8

## 机构原理（简化模型）

- 长骨根部铰接在上巢（固定端），张角 θ 在收合 3° ↔ 展开 68° 间变化；
- 撑骨一端铰接在长骨距上巢 8 单位处，另一端汇于下巢；下巢高度由撑骨定长约束解出；
- 尾骨绕骨关节回折，折角收合 174° ↔ 展开 −10°，形成“三折”包裹；
- 中棒三节按开合进度同步伸缩（总高 32 ↔ 44）。
